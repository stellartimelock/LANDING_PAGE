6. Third-Party Services

The application integrates with the following third-party services. Each is subject to its own terms of service and privacy policy:

  • Stellar Network (Horizon API & Soroban RPC) — For querying blockchain state and submitting transactions. No user data is shared beyond the public key and signed transaction envelopes that are publicly visible on-chain.
  • SimpleSwap — For non-custodial cross-chain asset swaps. When you initiate a swap, the destination address you provide is shared with SimpleSwap to complete the transaction. No seed or private key is ever shared.
  • Google Drive API — For encrypted backup storage. Only opaque AES-256 encrypted blobs are transmitted. Google never sees plaintext data.
  • Google Calendar API — For optional bill reminder sync. Only calendar events you create through the app are written.
  • Firebase (Android only) — For crash reporting and privacy-safe analytics. No personally identifiable information is collected.
  • European Central Bank (ECB) & Stellar Horizon — For fiat exchange rate data. Public, no user data is shared.
